3. Pose and animate

Frames start at 0. Hold a key for 350ms to select and drag it. Dropping onto another key replaces that key.

Angles are pose offsets from the guide rest orientation, in degrees. Non-Root has only Z enabled. Copy/Paste changes the current pose; Key full pose records it at the current frame. Playback interpolates keys; transforms include translation, quaternion rotation and scale.
4. UV layout
No UV selection
Two fingers zoom/pan. Zoom stays under the pinch center; wheel zoom stays under the cursor. Select: tap, or drag a rectangle. Move/Rotate/Scale: select first, then drag. Island packing keeps existing island shapes and uses non-overlapping padded bounding boxes; it cannot fix overlaps inside an island. New triangle UVs do guarantee separate faces, at the cost of many seams. UV edits do not rebake existing texture pixels. Photos/files options invoke Safari’s system picker; available sources depend on iOS.
5. Export

Exports only Lego parts + actual skeleton + 1.0 weights + UVs + animation + imported/painted texture. Guide geometry and editor helpers are excluded. Save the editable project as well. Internet required; not an offline PWA.
