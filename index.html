1 · Import and project

Y is up. Import keeps geometry and UVs, not external OBJ materials/textures. Separate parts are detected by connected geometry. Save a project regularly; closing or refreshing this page loses unsaved work.

2 · Rigid part binding

Selected part is orange. Each vertex has exactly one bone influence at weight 1. Initial assignments and pivots are guesses: correct them before animating. L means character left (+X).
Edit selected joint pivot (rest pose)

Move the joint to the actual shoulder, wrist, hip or neck. Editing pivots resets the preview to rest pose but keeps animation keys.

3 · Pose and animate

Set time, rotate a bone, then key the pose. Repeat at another time. All bones are keyed together. Playback interpolates rotations. For a loop, key the same pose at the start and end. Root translation below can be keyed too.

4 · UV layout

Guaranteed-separated triangle cells inside one 0–1 tile, with padding. This is a conservative fallback, not an efficient joined-island unwrap: many seams and wasted space are expected. Existing texture alignment is lost when generating new UVs. Preview shows all parts.

5 · Export

Tap the resulting file link to save/share in Safari. Includes real skin weights, skeleton, UVs, and one animation clip if keyed. Does not include a painted texture. Internet is needed for this version; Home Screen installation does not make it offline.
